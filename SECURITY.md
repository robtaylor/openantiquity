# Reporting a security problem

If you find a way to read what OpenAntiquity keeps back, to act as someone else, or to harm the service or the people who use it, please tell us privately and not in a public issue.

## How to report

Open the repository's **Security** tab on GitHub and choose **Report a vulnerability**. That sends a private report that only the maintainers can read. You need a GitHub account.

Say what you did, what happened, and what you expected. The address of the page and the time help us find it.

## What to leave out

- Don't open a public issue or a pull request that describes the problem before it is fixed.
- Don't include where a protected finding is. Its title or its public id is enough for us to find it.
- Don't read, change or delete other people's data to prove the point. Stop at the first sign that you could.

## What is in scope

The code in this repository and the service at openantiquity.org. Problems in a map or record service we draw from belong with whoever runs it.
