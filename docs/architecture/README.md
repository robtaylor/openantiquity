# Architecture

The current design of Field Club, by area. Each area is a **reference** doc: what the code does today, present tense, no rationale and no dead history. The *why* behind each choice lives in the [decision records](decisions/README.md), linked from the section it explains. The *not-yet-built* work lives in each doc's Implementation status section and in [plans](../plans/).

If you're an agent or a new reader, start here: this page maps every area to its current-state doc and the decisions behind it.

No area docs exist yet, because the first code is still being built. Each area gets its doc when its code lands. Until then the design being built is in [the build contract](../ARCHITECTURE.md), and the decisions so far are in the [decision index](decisions/README.md).
