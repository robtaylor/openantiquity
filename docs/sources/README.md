# Source catalogue

This catalogue records what a research pass found on 2026-11-10 about other people's data services: LIDAR elevation, site records for the four nations, finds, literature, gazetteers, map layers and the link templates of external viewers. Every page is a set of dated observations about someone else's service, written in the past tense. None of it describes what Open Antiquity's code does, because none of it is built. Each source carries a reuse class and a suggested access mode. [Decision 0004](../architecture/decisions/0004-field-club-is-non-commercial.md) defines the four reuse classes: `open`, `share_alike`, `non_commercial` and `link_only`. [Decision 0007](../architecture/decisions/0007-the-record-index-stores-only-what-licences-allow.md) defines the three access modes: `bulk` (downloaded and stored), `live` (queried by the user's browser and never stored on our servers) and `deeplink` (a link to the publisher's own page). A publisher that blocked scripts or forbade harvesting is `deeplink` whatever its licence. Where a first report and a later follow-up disagreed, the pages give the later one and say that they disagreed. Where something was not tried, the pages say "not tested".

The research also tested prior-art products and a few product APIs, among them YouTube oEmbed and per-channel RSS feeds, the Zooniverse Panoptes API, the iNaturalist API, the OpenStreetMap Notes API and the MapRoulette API. They are not record sources, so no page here lists them. The legal, sign-in and guidance references and the papers on LIDAR visualisation are also outside the catalogue. The spikes below cover them.

Three machine-readable work-lists were derived from these pages on 2026-11-10 and are kept in `worklists/`: `sources.json` (every storable and live source with its tested request, licence, attribution and field names), `map-layers.json` and `deep-links.json`. They are inputs for building the connectors and the layer catalogue. Once a source has a connector, the connector is the record of how it is read.

The evidence is summarised in three spikes: [open site records](../architecture/decisions/spikes/open-site-records.md), [open LIDAR elevation](../architecture/decisions/spikes/open-lidar-elevation.md) and [browser terrain rendering](../architecture/decisions/spikes/browser-terrain-rendering.md). The permissions still being sought from record holders, LIDAR publishers and others are in [owner actions](../plans/owner-actions.md).
